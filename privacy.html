개인정보처리방침

DevDocsMirror Privacy Policy · 적용일: 2026-10-14

이 정책은 운영자 Nv6001이 본인 계정에서 사용하는 DevDocsMirror에 적용됩니다. 지정한 관리문서의 자동 미러링을 운영하며, 아래 내용은 현재 적용하는 데이터 처리 기준입니다.

1. 접근·처리하는 데이터

  • 운영자가 지정한 GitHub 저장소의 선정된 관리문서 내용과 파일 경로, 브랜치·커밋 정보.
  • 지정한 Google Drive 미러 폴더와 파일의 ID, 이름, 상위 폴더, 내용 및 갱신·검증에 필요한 메타데이터.
  • Google OAuth 인증정보 및 접근·갱신 토큰.
  • 동기화 결과 확인에 필요한 실행 시각, 문서 경로·해시, 성공·실패 상태.

관리문서 본문에 개인정보가 포함돼 있으면 그 정보도 문서의 일부로 복사될 수 있습니다. 미러링 대상은 운영자가 필요한 범위로 선정합니다.

2. 이용 목적과 범위

Google Drive 데이터는 지정된 문서 미러의 조회·생성·갱신, 내용 일치 검증 및 동기화 기록 관리에만 사용합니다. Google 인증에서 허용한 범위와 별도로, 자동화 코드는 설정에 등록된 대상 폴더와 허용 문서에 처리 범위를 제한합니다.

데이터를 광고, 판매, 사용자 프로파일링 또는 AI 모델 학습에 이용하지 않습니다. 자동 미러링 과정에서 별도의 AI 서비스에 문서 내용을 전송하지 않습니다.

3. 저장 위치와 보관

문서 정본은 원래 GitHub 저장소에, 사본과 미러 검증 기록은 운영자의 Google Drive에 저장합니다. 두 서비스에서의 접근 가능 범위는 운영자가 설정한 저장소·파일·폴더 권한을 따릅니다.

Google 인증정보와 갱신 토큰은 로컬 최초 인증 과정에서는 운영자 PC의 비공개 설정 위치에 보관하고, GitHub 자동 실행에 필요한 값은 GitHub Actions의 Secrets에 보관하도록 구성합니다. 공개 사이트나 저장소 소스, 실행 로그에 인증정보를 기록하지 않습니다.

문서 내용은 실행 중 필요한 기간에 한해 작업 환경에서 처리하며, 공개 로그나 공개 빌드 산출물로 보관하지 않도록 구성합니다. 실행 로그에는 진단에 필요한 최소한의 메타데이터만 남깁니다. 미러 파일과 검증 기록은 운영자가 삭제할 때까지 보관될 수 있으며, Google Drive의 버전 이력·휴지통 및 GitHub의 실행 로그 보관에는 각 서비스의 정책과 설정이 적용됩니다.

4. 서비스 제공자와 공개 범위

GitHub는 저장소·GitHub Actions 실행 환경·Secrets 및 이 소개 사이트의 호스팅을, Google은 OAuth 인증과 Drive 저장을 제공합니다. 문서 데이터는 지정된 GitHub 실행 환경과 Google Drive 사이에서 처리됩니다. 앱이 임의의 제3자에게 데이터를 판매하거나 공유하는 기능은 사용하지 않습니다.

이 소개 사이트 자체에는 로그인, 방문자 분석 스크립트, 광고 또는 앱이 설정하는 쿠키를 추가하지 않습니다. 다만 GitHub Pages는 사이트 방문자의 IP 주소 등 호스팅 보안에 필요한 정보를 처리할 수 있습니다. 각 서비스의 처리는 GitHub 개인정보처리방침 및 Google 개인정보처리방침을 따릅니다.

5. 접근 철회와 삭제

운영자는 GitHub Actions 자동 실행을 비활성화하고 저장된 Secrets·로컬 인증 파일을 삭제해 자동화를 중단할 수 있습니다. Google 계정의 연결된 앱 설정에서 DevDocsMirror의 접근 권한을 철회할 수 있습니다. 권한 철회만으로 이미 저장된 Drive 사본이 삭제되지는 않으며, 사본과 기록은 Drive에서 별도로 관리합니다.

6. Google API 데이터 사용

Google API를 통해 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용(Limited Use) 요건을 포함한 Google API Services User Data Policy를 준수하도록 구성합니다.

In English: DevDocsMirror processes selected GitHub documents, designated Drive files and metadata, OAuth credentials, and minimal synchronization records solely to maintain a personal documentation mirror. It does not use these data for advertising, sale, profiling or AI training. Planned automation uses GitHub Actions and Google Drive. Access can be revoked through Google Account connections, and stored mirror copies can be managed separately in Drive.
