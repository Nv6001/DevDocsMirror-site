DevDocsMirror

Personal development documentation mirror

DevDocsMirror는 운영자 본인의 개발 프로젝트 관리문서를 GitHub에서 Google Drive로 복사하는 개인용 도구입니다. GitHub 문서를 정본으로 두고, Drive에서 읽기용 사본을 확인할 수 있도록 구성합니다.

현재 상태: 설정 준비 중. 자동 미러링은 아직 활성화되지 않았습니다. 이 페이지는 계획된 기능과 데이터 처리 기준을 설명합니다.

예정된 기능

  • 명시적으로 지정한 저장소·브랜치·커밋에서 선정된 관리문서를 읽습니다.
  • README, 상태문서, 설계·의사결정·변경기록 등 허용한 문서를 원래 경로와 파일명으로 복사합니다.
  • 지정한 Drive 미러 폴더의 기존 파일을 같은 파일 ID로 갱신하고, 새 관리문서는 추가합니다.
  • 기준 커밋, 복사 시각, 원본 경로, 파일 해시와 검증 결과를 기록합니다.

Google Drive 접근 목적

본인 계정의 지정된 문서 미러 위치를 읽고 파일을 생성·갱신하기 위해 Google OAuth 동의를 받습니다. 미러링은 GitHub에서 Drive로 한 방향으로 수행하며, Drive의 사본을 독립적인 정본으로 취급하지 않습니다.

자동화의 처리 범위는 설정에 등록된 문서와 대상 폴더로 제한합니다. 운영 녹음, 업무 자료, 사진, 운영 DB 및 실행 프로그램은 이 문서 미러링의 대상에 포함하지 않습니다. 원격에서 사라진 문서를 자동으로 삭제하는 기능은 사용하지 않습니다.

운영 환경과 개인정보

예정된 실행 환경은 GitHub Actions이며, 자동 미러링 자체에는 AI 모델이나 전사 API를 사용하지 않습니다. Google과 GitHub를 이용하는 과정의 데이터 처리와 인증정보 보관 기준은 개인정보처리방침에서 확인할 수 있습니다.

This personal tool mirrors selected project documentation from GitHub to designated Google Drive folders. Automation is not yet enabled. Google Drive access is used to read, create and update the designated mirror files.
